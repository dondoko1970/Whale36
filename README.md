## 自設計キーボード「Whale36」
- カラムスタッガード配列、36キーのコンパクトな自作キーボード。
- PORONフォームによるガスケット構造により、ソフトな打鍵感。
- LEDを搭載。
- Vialに対応し、キーマップを自由に変更することが出来ます。
- 複数レイヤーや、同時押しでの入力(VialのCombo機能)を活用し、通常のキーボードと遜色なく使用することが出来ます。
- マイコンとUSB端子を分離することで、コンパクトな設置面積と最小限の高さ(ゴム足からスイッチプレート上部まで??mm)を両立しています。
